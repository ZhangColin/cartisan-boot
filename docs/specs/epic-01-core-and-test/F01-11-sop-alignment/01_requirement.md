# Feature: F01-11 SOP 对齐与文档完善

## 背景

Epic 1 完成后进行审计，发现虽然整体按 SOP 落地良好，但在以下方面存在改进空间：

1. **PIT 变异测试**未真正成为流程门禁（工具已配置，但执行和记录未标准化）
2. **Docker 环境依赖**说明不清晰，新成员运行测试可能遇到环境问题
3. **CLAUDE.md**缺少环境要求和门禁说明
4. 项目缺少 **README.md** 作为快速入口

## 目标

- 补充项目文档，确保环境要求和门禁标准清晰可执行
- 为后续 Epic 建立可复用的文档模板和脚本

## 范围

### 包含（In Scope）

1. CLAUDE.md 新增内容
   - 开发环境要求（Docker 依赖说明）
   - 质量门禁（测试命名、PIT 变异测试）

2. 项目根目录创建 README.md
   - 项目简介
   - 快速开始（含环境要求）
   - 测试分层说明
   - 开发指南链接

3. PIT 门禁脚本
   - 创建 `scripts/run-pitest.sh`
   - 支持模块化执行
   - 输出报告路径提示

4. SKILL.md 更新
   - 新增 TOOL-004（PIT 执行说明）

### 不包含（Out of Scope）

- 修改已有 Feature 的代码实现
- CI/CD 流水线配置（后续 Epic 考虑）
- 历史交叉审查记录追溯（仅面向未来）

## 验收标准（Acceptance Criteria）

### AC1: CLAUDE.md 更新

- [ ] 新增「开发环境要求」小节，说明 Docker 依赖
- [ ] 新增「质量门禁」小节，说明测试命名和 PIT 要求
- [ ] 内容与 SOP v0.4 保持一致

### AC2: README.md 创建

- [ ] 包含开发指南文档链接

### AC3: PIT 脚本创建

- [ ] `scripts/run-pitest.sh` 可执行（chmod +x）
- [ ] 接受模块名参数
- [ ] 执行后输出报告路径

- [ ] 新增 TOOL-004 规则
- [ ] 格式与现有规则一致
