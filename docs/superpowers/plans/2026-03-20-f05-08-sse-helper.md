**目标:** 将 `Flux<ChatStreamEvent>` 转换为 Spring MVC `SseEmitter`，封装超时、异常、客户端断开等边界情况。

**架构:** Spring Bean (`SseHelper`) + 配置属性类 (`SseProperties`)。通过 Reactor 操作符订阅 Flux，将事件逐条发送到 SseEmitter，处理各种完成信号。

**技术栈:** Spring Web (SseEmitter), Reactor Core (Flux), Spring Boot (@ConfigurationProperties)

## Task 5: 实现 toSse 核心逻辑

- [ ] **Step 1: 实现 toSse 方法**

```java
public SseEmitter toSse(Flux<ChatStreamEvent> events,
                        Consumer<TokenUsage> usageCallback) {
    // 创建 SseEmitter，配置超时
    SseEmitter emitter = new SseEmitter(properties.getTimeout().toMillis());

    // 配置超时处理
    emitter.onTimeout(() -> {
        emitter.complete();
    });

    // 配置错误处理
    emitter.onError(ex -> {
        emitter.completeWithError(ex);
    });

    // 用于累积最后一个 usage
    AtomicReference<TokenUsage> lastUsage = new AtomicReference<>();

    // 订阅 Flux，发送事件
    events.doOnNext(event -> {
        try {
            emitter.send(event);
            // 累积 usage
            if (event.usage() != null) {
                lastUsage.set(event.usage());
            }
        } catch (IOException e) {
            emitter.completeWithError(e);
        }
    })
    .doOnError(ex -> {
        emitter.completeWithError(ex);
    })
    .doOnCancel(() -> {
        // 客户端断开，Flux 自动取消
    })
    .doFinally(signalType -> {
        // 回调最后一个 usage
        if (usageCallback != null) {
            usageCallback.accept(lastUsage.get());
        }
        emitter.complete();
    })
    .subscribe();

    return emitter;
}
```

## 实现注意事项

1. **TDD 顺序**: 先写测试，再实现，确保测试驱动
2. **频繁提交**: 每个 Task 完成后立即 commit
3. **Usage 提取**: 使用 `AtomicReference` 在 `doOnNext` 中累积最后一个 usage，避免在 `doFinally` 中重新订阅已终止的 Flux
4. **异常处理**: Flux 错误和发送失败都应调用 `completeWithError()`
5. **超时处理**: 超时是正常场景，应 `complete()` 而非抛异常
